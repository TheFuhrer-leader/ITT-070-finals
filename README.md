 Inventory & Purchase Order System

 Project Description
This is a console-based Inventory and Purchase Order Management System built in Python. It helps a small business manage products, vendors, stock levels, purchase orders, and generate reports.

 Features
- Add, edit, search, and deactivate products
- Vendor management
- Create and receive purchase orders
- Real-time inventory updates
- Multiple search and sort options
- 5 different reports
- Save/Load data using JSON
- Input validation and error handling

 Required Files
- main.py
- models.py
- inventory_manager.py
- file_manager.py
- reports.py
- README.md
- reflection.md
- code_explanation.txt
- sample_data.json
- data.json (created by program)

 How to Run
1. Download all files into one folder
2. Open terminal in that folder
3. Run: `python main.py`

 Data Storage
All data is saved in `data.json` using JSON format. The program automatically loads data when started and saves when exiting.

 Unique Feature
**Reorder Suggestion System** - The low stock report shows suggested reorder quantities.

**Business Scenario**: "TechOffice Supplies" - Selling office equipment and electronics.
